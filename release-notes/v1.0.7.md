# Mod Uploader by Nevermore 1.0.7

- Added Spiffo with a green checkmark to success messages, including saved in-game icons.
- Publication success now stays visible for three seconds. Click anywhere on the overlay to dismiss it early; Enter and Escape work too.
- Moved per-mod paths and preparation scripts into **Mod settings**, opened with the gear beside the selected mod's title. Language and shared paths remain in **Settings**. Saving either section only changes its own settings.
- Update notes display a formatted BBCode preview outside editing. Click the text to edit the original BBCode; drafts and selection are preserved.
- Preview supports headings, text styles, lists, quotes, code and tables. Image URLs and video links stay as references without network downloads.

Download `ModUploader.exe`; no installer, separate images or ZIP are needed. The EXE uses the existing self-signed Nevermore certificate and timestamp; this does not establish public Windows trust.

Offline and UI checks passed, including settings isolation, preview/edit switching, three-second dismissal and click dismissal. English/Russian layouts were visually inspected. No real Steam publication was performed.
