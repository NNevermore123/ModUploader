# Mod Uploader by Nevermore 1.0.9

Prepare, test and publish Project Zomboid mods from a standalone Windows app using your installed Steam session.

## New in 1.0.9

- **Install locally** copies the selected mod's prepared Source into your user-profile `Zomboid/mods` folder for game testing.
- Review the exact source, destination and obsolete files before installing. Confirmed obsolete local backup/archive files can be removed without creating new backups.
- **Launch game** starts Project Zomboid through Steam using the green-outlined sidebar button.
- Mod actions remain on the same line as the mod icon and title, with larger buttons and filled vector icons. Navigation and settings icons are clearer too.
- Successful local installation shows Spiffo with a green check. It closes after three seconds or on click.
- The public README now explains setup, folder layout, local testing, existing updates and new listings, with current English screenshots.

## Included features

- Update existing Workshop items or create a new listing with a saved Workshop ID.
- Independent description/preview switches for updates; required title, description, preview and visibility for new listings, with Private selected by default.
- Optional preparation scripts, payload synchronization, file-hash checks, upload progress and error details.
- BBCode controls in both text editors, a formatted update-note preview, and a separate source in-game icon editor.
- English by default and instant English/Russian switching without losing the current fields or options.

## Download and use

Download **ModUploader.exe** from this release and follow the [README](https://github.com/NNevermore123/ModUploader#readme). There is no installer or ZIP. **SHA256SUMS.txt** contains the EXE checksum; **RELEASE_NOTES.md** is a copy of these notes.

Requires Windows x64, .NET Framework 4.8 or newer, an installed Steam copy of Project Zomboid, and Steam running under the Workshop item's owner account. PowerShell 7 is needed only for a configured preparation script. No Steam API DLL is redistributed.

Local installation copies the current Source; it does not run a build script or upload anything. Prepare/build your mod first, install it locally, enable it in the game and test it before publishing.

## Verification

Offline and UI checks passed, including synthetic local installs, obsolete-backup cleanup, preserved drafts/options, and completion dismissal by timer and click. English and Russian renders were inspected at normal and compact sizes. Automated tests did not launch the game or submit real Steam create/update operations.

The EXE's cryptographic Authenticode signature, PE digest and timestamp are verified during release preparation. It uses the existing **self-signed Nevermore certificate**; this does not establish public Windows trust or remove SmartScreen warnings.
