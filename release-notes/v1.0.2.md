# Mod Uploader by Nevermore 1.0.2

## What's new

- **Delete mod** offers a choice: remove the app entry, delete the local Workshop folder, or delete Workshop plus the mod's source files. File deletion requires a separate confirmation with the exact folders. The Steam listing is preserved.
- **Find mods** now removes entries whose source folder or mod.info is missing. Entries removed manually stay hidden until added again using **+ Dev folder**.
- Both text editors now offer Steam BBCode controls for headings, bold, italic, underline, strike, lists, quotes, code, spoilers, links, images, tables, dividers and embeds.
- Workshop preview images are shown without cropping. Click an image to open a larger view.
- Added **In-game icon** editing: choose the mod version, select a PNG and apply it to the source files. Icons appear in the sidebar and selected-mod header. Prepare/publish to include the change in your Workshop update.
- Removed the redundant description hint.
- Added a larger transparent mascot logo and matching Windows application icon.
- English and Russian remain available in Settings.

## Download

Download `ModUploader.exe`. No installer or ZIP is required. The EXE contains its logo and icon; no extra asset files are needed. `SHA256SUMS.txt` contains the checksum.

Requires Windows x64, .NET Framework 4.8+, installed Project Zomboid and a running Steam client. The game can stay closed. The EXE is self-signed by Nevermore and timestamped; Windows may still show an untrusted-publisher warning.

## Validation

Offline checks passed for missing-mod cleanup, persistent removal, constrained deletion and confirmation guards, source-icon editing/version isolation/alpha preservation/staging, BBCode and language behavior. UI tests verify icon refresh without losing drafts, and both language layouts were visually inspected. The EXE signature and checksum were verified. Deletion tests used synthetic folders only; no real mod was deleted or published. Actual in-game icon rendering and Steam publication remain untested.
