# Mod Uploader by Nevermore 1.0.4

## What's new

- Replaced the bottom status panel with just **Prepare files** and **Publish** buttons.
- Preparation and publication now show a centered running Spiffo, with two alternating poses, a light bounce, a soft oval shadow and translucent wind streaks.
- A dark translucent overlay blocks the rest of the app while an operation runs.
- The progress bar and changing status appear below Spiffo. Unknown phases use an indeterminate bar; Steam supplies upload percentages.
- Successful completion shows Spiffo leaning on a green checkmark, with a softly pulsing green glow, for one second.
- Errors stay visible until dismissed. Workshop agreement instructions remain available when Steam requires them.
- Both running frames use proportionate orange legs. All three illustrations are transparent and embedded in the EXE.

## Download

Download `ModUploader.exe`. No installer, ZIP or separate image files are needed. `SHA256SUMS.txt` contains the checksum.

Requires Windows x64, .NET Framework 4.8+, installed Project Zomboid and a running Steam client. The game can stay closed. The EXE uses the existing self-signed Nevermore certificate and a timestamp; Windows may still show an untrusted-publisher warning.

## Validation

Offline and UI checks passed for animated frame switching, bounce/shadow/wind, background blocking, progress mapping, completion timing and animation cleanup, error dismissal and existing mod-management features. English and Russian layouts were inspected, including the minimum window size. PNG alpha, executable signature and checksum were checked. No real mod was deleted and no Steam item was created or updated during validation.
