# Mod Uploader by Nevermore 1.0.3

## What's new

- Redesigned **Delete mod** as an internal overlay without a separate Windows title bar.
- The rest of the app dims and stops accepting input until the dialog closes.
- Added transparent Spiffo artwork beside a burning barrel, with dropped building tools and a gently flickering fire glow.
- Replaced the dropdown with three exclusive choices and explanatory tooltips.
- Centered the heading and mod name, with **Cancel** and **Delete** below the choices.
- File deletion keeps a separate exact-path confirmation inside the overlay. Cancel or Escape closes it without changing the mod or draft.
- English and Russian layouts support the minimum window size. Animation respects the Windows animation preference.

## Download

Download `ModUploader.exe`. All artwork is embedded; no extra files, installer or ZIP are required. `SHA256SUMS.txt` contains its checksum.

Requires Windows x64, .NET Framework 4.8+, installed Project Zomboid and a running Steam client. The game can stay closed. The EXE uses the existing self-signed Nevermore certificate and a timestamp; Windows may still show an untrusted-publisher warning.

## Validation

Offline and UI checks cover deletion guards, both languages, background blocking, exclusive selection, tooltips, exact-path review, Cancel/Escape, draft preservation, focus restoration and animation cleanup. English/Russian renders were inspected at regular and minimum size. The signature and executable checksum were verified. File-deletion tests use synthetic folders; no real mod was deleted or published to Steam.
