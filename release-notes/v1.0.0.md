# Mod Uploader by Nevermore 1.0.0

Publish Project Zomboid mods from your dev folders through Steam without launching the game.

## Included

- Dark home screen with existing-mod and new-publication workflows.
- Separate toggles for replacing an existing listing's description and preview.
- Steam BBCode changelogs, file preparation and upload progress.
- New Workshop ID persistence and protection against blind duplicate creation.
- Always-visible Steam author and Buy Me a Coffee links.

## Download and run

Download `ModUploader.exe`; `SHA256SUMS.txt` contains its SHA-256 checksum. Windows x64, .NET Framework 4.8+, installed Project Zomboid and a running Steam client are required. The game itself can remain closed. Additional build tools depend on each mod's preparation script.

The current interface is in Russian. The EXE is self-signed as Nevermore and timestamped; Windows may still show an unknown/untrusted publisher warning. No private key is included.

## Validation

Offline payload, UI, signature and tamper-detection checks passed. Read-only Steam connection and ownership lookup passed. Real Workshop creation/publication has not been exercised by those checks.
