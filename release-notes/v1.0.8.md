# Mod Uploader by Nevermore 1.0.8

- Preparation scripts are now optional for all mods, including Java mods.
- Leave the script field empty to upload already prepared files. No PowerShell is needed when no script is selected.
- Configured scripts still run before staging. A missing script or a failed run stops publication.
- Updated English and Russian settings hints.

Existing JAR signature presence checks remain unchanged. The uploader copies prepared JARs and their signatures; it does not build or sign mods automatically when the script is empty.

Offline and UI checks passed, including Java staging without a script and unchanged payload/signature bytes. No real Steam publication was performed.

Download `ModUploader.exe`; no ZIP, installer or separate assets are needed. The EXE is self-signed by Nevermore and timestamped; this does not establish public Windows trust.
