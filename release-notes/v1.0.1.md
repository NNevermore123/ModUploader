# Mod Uploader by Nevermore 1.0.1

## What's new

- English is now the default interface language, including when upgrading from 1.0.0.
- Choose **Settings → App language → English / Русский** to switch instantly. Your choice is saved automatically.
- Navigation, forms, tooltips, progress and application error messages are available in both languages.
- Your update notes, descriptions, paths, visibility and description/preview switches stay unchanged when you switch languages.

## Download

Download and run `ModUploader.exe`. No installer or ZIP is needed. `SHA256SUMS.txt` contains its SHA-256 checksum.

Requires Windows x64, .NET Framework 4.8+, installed Project Zomboid and a running Steam client. The game can stay closed.

The EXE is self-signed by Nevermore and timestamped. Windows may still show an untrusted-publisher warning.

## Validation

Language defaults, migration, persistence and fallback checks passed. UI tests cover live switching, preserved user input and publication flags, and new-listing safeguards in both languages. English and Russian layouts were visually checked. Offline payload checks and signature verification passed. No real Steam item was created or updated during testing. External script output and Windows diagnostics may use their own language.
