# Changelog

## 1.0.0

Initial standalone release of Mod Uploader by Nevermore.

- Dark WPF interface, home screen, metadata toggles and upload progress.
- Existing Workshop updates and new listing creation with saved IDs.
- Dev-project staging, optional preparation scripts and SHA-256 checks.
- Authenticode self-signature and timestamp.

See [release notes](release-notes/v1.0.0.md) for requirements and validation limits.
